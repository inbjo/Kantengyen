# 托管、机器人策略实验（2026-10-13）

最终选择人数自适应策略 `Adaptive`，机器人、托管与断线代打共用。有限局同时使用公开积分、剩余局数调整风险；无限局保持单局长期收益目标。最终选择的整桌风险系数及独立复核结果见下文。

## 信息边界与公平发牌

策略只接收 `Observation`：自己的手牌、已出牌、各座位剩牌数量、公开出牌数量、当前牌型、轮次位置、牌堆张数与炸弹倍率。`MatchContext` 只接收自己的累计分数、其他参与者最高公开分数和剩余局数（含当前局）；服务器也计入已经离桌但保留在总榜的玩家。不传入对手具体手牌、牌堆顺序或下一张牌。测试随机重分配隐藏牌 200 次，逐一验证五套策略和整桌策略选择不变。

正常发牌使用 `StdRng::from_os_rng()` 和 `SliceRandom::shuffle()`。发牌函数只接收人数、可选庄家及随机源，不接收身份、积分、机器人状态；不按手牌强弱重抽。测试用固定种子便于复现，真实对局每局从操作系统取随机种子。练习保持预设教学牌。

35 万次生产发牌函数统计验证（2–8 人各 5 万次）：逐座位检查全部 54 张牌的入手概率，并分别检查庄家 6 张／非庄家 5 张的分布和随机庄家分布。所有检查通过，座位单牌最大标准化偏差为 3.43，角色单牌最大偏差为 3.96，预设多重检查门槛 6.5。每局检查一副牌无重复、无遗漏。统计通过说明未发现分布异常，不等于数学上证明随机性。庄家多一张及赢家先手是既有玩法规则，不通过改发牌抵消。

## 候选算法

| 策略 | 主要机制 |
| --- | --- |
| Legacy | 昨天的直接走完、对子配王炸弹、报单时最大牌策略，作为对照 |
| Shape | 对结构候选做手牌分组动态规划，优先减少余牌和后续出牌组数，避免剩单独万能牌 |
| Control | Shape 加入已出牌推算的接牌概率、2 的保留价值、报单防守和抢回领出权后的摸牌成本 |
| Score | Control 加入炸弹倍率的收益与输分风险、关门底分 |
| Adaptive | 2–4 人使用 Score；5–8 人强化出牌机会与余牌组合，使用公开接牌风险作辅助 |

所有算法使用同一份真实规则与计分，包含只接大一级、2 的特殊接法、万能牌不能单出、炸弹累计倍率、关门扣 10 分、抢回领出权后的补摸和流局。

未知牌来自整副牌减去自己的手牌和公开已出牌，用超几何概率估算单张／对子与炸弹的接牌可能。顺子和多个对手间的联合概率采用近似；它们是启发式风险分数，并非校准的真实胜率。最多 12 张手牌使用结构候选的分组 DP，大手牌使用有界近似，避免异常长手牌阻塞服务器。未作无限深度搜索或理论最优声明。

## 单局筛选与独立测试

探索阶段四次各 10 万局用于调整权重（`strategy-screen*.json`）；最终五策略筛选为 5 万组相同牌／相同座位／相同先手的配对测试，共 25 万局。筛选种子 `20261013`。

权重冻结后的独立测试种子 `2026101409`，10 万组配对测试、五策略共 50 万局。覆盖 2–8 人，轮换被评估座位，对手在五套策略之间等量分块切换。每局检查合法出牌、终局、牌张守恒与计分零和；未出现停滞。

| 策略 | 平均每局得分 | 胜率 | 失败时平均剩牌 |
| --- | ---: | ---: | ---: |
| Legacy | -0.63335 | 21.554% | 2.690 |
| Shape | 0.27979 | 25.202% | 2.603 |
| Control | 0.19887 | 25.797% | 2.627 |
| Score | 0.21851 | 25.813% | 2.627 |
| Adaptive | **0.31024** | **26.074%** | 2.634 |

Adaptive 比 Legacy 配对平均每局多得 **0.94359 分**，95% 正态近似置信区间约 **[0.8730, 1.0142]**；胜率增加 **4.520 个百分点**。Adaptive 的平均得分、胜率为候选中最高；Shape 的败局剩牌最少。Adaptive 对 Shape 的得分差为 0.03045，95% 区间约 [-0.0037, 0.0646]，不能声称已显著优于 Shape。五策略都仍可能在特定人数／对手类型下落后，分人数和分对手明细保留在原始 JSON。

本机 release 模拟中 Adaptive 平均决策约 3.2 微秒，观察到的最大值约 1.06 毫秒；这是本机测试观测，不是生产延迟保证。

## 整桌局数与累计积分

有限桌的风险压力由公开分差、当前可能结算的分值和剩余局数构成。剩余局数越少，落后者越倾向争取倍率，领先者越克制扩大风险；已参与出牌、明显领先且仅剩一两局时，长弱手可以主动放弃会放大输分的炸弹。能立即走完时始终走完。无限桌不采用临近终局的风险压力。

首轮比较三种整桌风险强度：0（只优化单局）、0.5、1.5。2–8 人 × 8／16／32 局 × 随机／赢家先手 × 领先／持平／落后三种公开积分，合计 12,600 组配对整桌、37,800 次完整桌、705,600 局。起始积分分别为本座 +24／0／-24、下一座反向对应分数，全桌总分为 0；这属于明确构造的积分压力场景。并列冠军按并列人数分摊。三个候选使用同一份每局牌序，赢家先手因实际赢家不同而发生先手差异，属于策略造成的结果。

对手共用 Adaptive，风险权重 0.5，各自只能使用自己可见的信息。首轮风险系数 1.5 的平均冠军率最高：24.512%，对照为 24.452%；配对差 0.060 个百分点，95% 区间约 ±0.088 个百分点，尚未证实显著改进。系数 1.5 的平均每桌新增得分为 -0.247，对照 -0.260。

独立整桌复核种子 `2026101607`，扩展到 1／8／16／32／128 局及无限桌（观察 128 局）。长桌每格 20 组，其余每格 100 组。无限桌只用于长期得分比较，观察窗口末的冠军率不是无限桌的终局目标。复核完成 18,480 组配对整桌、55,440 次整桌运行、1,363,320 局。

| 整桌风险强度 | 观察窗口冠军率 | 平均每桌新增得分 |
| --- | ---: | ---: |
| 0：只优化单局 | 26.683% | -0.33853 |
| 0.5 | 26.756% | -0.25817 |
| **1.5：最终启用** | **26.878%** | **-0.09919** |

系数 1.5 相对对照的配对冠军率增加 **0.1948 个百分点**，95% 区间约 **[0.1087, 0.2809] 个百分点**；配对平均每桌多得 **0.23934 分**，95% 区间约 **[0.0822, 0.3964]**。这支持在本次场景分布下采用该风险调整，不保证对所有真人打法成立。起始积分压力场景与随机牌序仍可能影响结果。

| 总局数 | 对照冠军率 | 最终策略冠军率 |
| --- | ---: | ---: |
| 1 | 32.238% | 32.381% |
| 8 | 25.512% | 25.690% |
| 16 | 25.917% | 26.071% |
| 32 | 23.690% | 23.976% |
| 128 | 24.643% | 25.119% |

无限桌三种风险强度在所有对应牌序上得到完全相同的出牌结果与得分，验证没有应用人为终局压力。其窗口冠军率仅为观察统计，不参与无限桌目标。

累计执行的完整模拟为 **3,218,920 局**（探索 400,000 + 最终单局筛选 250,000 + 独立单局 500,000 + 整桌筛选 705,600 + 独立整桌 1,363,320），其中一部分是共享牌序的配对对照，并非全部独立牌样本；另外执行 350,000 次发牌公平性检查。

## 时间与语音

- 机器人／托管：要不起或直接走完 1 秒，普通决策 1.5 秒，至少六种合法出法或对手只剩一两张时 2 秒。服务器回合扫描间隔 200 毫秒，实际动作可能晚一个扫描周期。
- 真人自动过牌等待 1 秒；在线真人手动回合时限保持 30 秒。
- 移除“快出牌吧”的触发、素材、清单和素材生成项。5 秒即将超时提示保留。

```bash
cargo test --workspace
cargo clippy -p kantengyen-core --all-targets -- -D warnings
npm run build
```

`Cargo.lock` 固定测试随机数实现版本。当前策略可复现最终筛选、单局独立测试和整桌测试；四次早期探索报告记录的是当时权重，未作为最终独立验证。当前实现与报告文件摘要见 `provenance.json`。
